题目描述 (Problem Description)

在密码学与高级编译器混淆中，有一种常见的数据流保护机制称为“算术多项式混淆”。现给定一个长度为 N 的初始正整数序列 A = [a₁, a₂, ..., aₙ]。

你需要执行 M 次连续的混淆指令，每一项操作由三个整数 op, l, r 组成：

  • 操作 1 (加法异或卷积): 对于区间 [l, r] 内的所有元素，执行 aᵢ = (aᵢ ⊕ x) + (aᵢ & y) mod 998244353。
  • 操作 2 (逆序重构变换): 将区间 [l, r] 内的前 k 个最大元素按位取反并翻转排列。
  • 操作 3 (区间求和校验): 查询区间 [l, r] 的元素和对 998244353 取模的结果。

你的程序需要在规定时限内输出所有“操作 3”的校验值。如果答案计算溢出或区间未正确更新，系统将判定为错误结果（Wrong Answer）。

输入格式 (Input Format)

第一行输入两个正整数 N, M (1 ≤ N, M ≤ 100,000)，表示序列长度与操作次数。

第二行输入 N 个空格分隔的整数，表示初始数组 a₁, a₂, ..., aₙ。

接下来 M 行，每行描述一个操作，格式为：

  • 1 l r x y
  • 2 l r k
  • 3 l r

输出格式 (Output Format)

对于每个操作 3，单行输出一个整数代表该次区间求和校验的计算结果。

提示与数据范围 (Constraints & Notes)

• 子任务 1 (15分): N, M ≤ 1,000，无操作 2。
• 子任务 2 (30分): N, M ≤ 50,000，所有 x = 0。
• 子任务 3 (55分): N, M ≤ 100,000，无特殊限制。
