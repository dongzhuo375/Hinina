# contest

`contest.current(context)` / `contest.get(context, contestId)` / `contest.problems(context)` 需 contest.read；`contest.rank(context, {page, limit})` 需 contest.rank **∩** contest.read，缺任一返回 permission_denied 并指认缺失项。无当前比赛或请求其他比赛时 current/get 返回 null；problems/rank 未选中比赛返回 context_expired（与 submission.list 一致）。只读 Service 方法不调用 load_contest_with_problems，不会选择或切换比赛。

返回 contestId、纯文本 title（最多256字符）、startsAt、endsAt（UTC毫秒）、contestType（'acm'/'oi'，未知值归一 acm）、sealed（`seal_rank && seal_rank_time <= now`，与 RankView 同规则；解释性标志，不是安全闸门——真正的闸门是服务端封榜期间不下发通过状态）、sealedSince（封榜**开始**时刻，UTC 毫秒，仅封榜时非 null；服务端不下发结束时刻，故无 sealedUntil），不返回密码、HTML 描述或完整领域实体。

problems 返回 `{problemId, displayId, title, color}`：题号 ↔ 气球颜色映射，Hydro 无 color（空串透传）；title/color 按字节截断（≤256/≤64 UTF-8 字节，千题级比赛仍可编码）。rank 返回 `{rows, page, hasMore}`（**不带 total**——HOJ 的 total 含服务端前置条目且偏大，行数以去重后非打星行为准）：行含 rank（-1 打星）、teamKey（与 identity.userKey 同算法，可直接比对自身）、displayName、school、ac、totalScore、cells（key=displayId；含 solved/firstAc/acTime/errorNum/tryNum/score/afterContest，封榜期间 solved/firstAc 恒 false、acTime 恒 null）。不返回 uid（字段）、原始 username、realname、nickname、avatar、gender、totalTime 或任何原始响应。

displayName 由宿主按比赛 `rank_show_name` 解析（与前端 `resolveDisplayName` 同规则：realname/nickname/username 选字段，空回退 username，再回退 uid 文本），保证插件榜与 App 榜一致；为此 rank 每次额外读一次比赛元信息（仅名字解析，sealed/contestType 仍只来自 contest.current）。行 uid 为空（Hydro 无 raw 的 user cell）→ 整页 provider_error：空 uid 无法生成稳定 teamKey。行文本（displayName/school）按字节截断（≤96 UTF-8 字节，字符边界安全）。边界可组合：page 1..100、每页 ≤200 行、单行 ≤64 列、单页总 cells ≤6,000（顶满名字的 200×30 页仍可编码，病态内容由 1MiB 桥上限兜底）；行文本（displayName/school）按字节截断（≤96 UTF-8 字节，字符边界安全）；limit 是提示（Hydro 无视分页、整榜单页返回）；page 回显服务端实际页（Hydro 恒 1），hasMore = current < pages；跨页无事务快照按 teamKey 去重，不带 total。榜单查询另有每激活 6 次/分钟独立预算（HOJ 全榜重算昂贵）。PluginRankPage 刻意不带 sealed/contestType。
