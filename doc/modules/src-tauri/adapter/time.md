# adapter::time（时间解析）

> 源文件：`src-tauri/src/adapter/time.rs`

## 职责

把各 OJ 响应里的时间串折算成**秒级 UTC 时间戳**。放在 adapter 层是因为「服务端时间串的格式族」
是协议差异的一部分（HOJ 带毫秒与 `+0000` 后缀、Hydro 带 `Z`、自建部署可能带 `+08:00`），
而**两个 Adapter 需要同一套判据** —— 此前各写一份，结果「修好一个」不等于「修好全部」。

## 核心类型/函数

| 名称 | 签名 | 用途 |
|------|------|------|
| `parse_time` | `(raw: &str) -> i64` | 唯一公开入口；返回秒级 UTC 时间戳，`0` = 未设置/无法解析 |
| `try_parse` | `(s: &str) -> Option<(i64, i64)>`（私有） | 解析成功返回 `(UTC 秒, 原始偏移秒)`；失败返回 `None` |
| `split_timezone` | `(rest: &str) -> (&str, i64)`（私有） | 切出 `Z` / `±HHMM` / `±HH:MM` 偏移；**只扫时刻部分**（连日期一起扫会把 `2026-01-01` 误判成负偏移） |
| `epoch_secs` / `is_leap_year` / `leap_years_between` | 私有 | 纯 std 的日期折算，不引入时间库 |

## 支持的输入形态

- `2026-01-01T01:00:00.000Z`（Hydro 榜单/比赛文档）
- `2026-09-21T16:00:00.000+0000`（HOJ 实测：**带毫秒与偏移后缀**）
- `2026-01-01T09:00:00+08:00` / `+0800`（自建部署常见）
- `2024-01-01 08:00:00`（空格分隔、无时区 → 按 UTC 解释）
- `2024-1-1 8:00:00`（**非零填充**：按字段切分而非固定字节取位）
- `2026-01-01`（只有日期，时刻补 0）

## 直接依赖

- `tracing`（`warn`）

## 被依赖

- `adapter/hoj/mod.rs`（`HOJAdapter::parse_time` 委托给它）
- `adapter/hydro/types.rs`（`pub use` 再导出，供 `hydro/mod.rs` 与既有测试使用）

## 逻辑流程

```
parse_time(raw)
  ├─ trim 后为空 → 0（「未设置」，不告警）
  └─ try_parse
       ├─ None → warn!(raw) + 返回 0
       └─ Some((secs, offset))
            ├─ offset != 0 → warn!(raw, offset_secs)   // 部署时区配置异常的第一现场信号
            └─ 返回 secs
```

设计要点：

- **失败不静默、也绝不 panic**：时间解析失败不该让整场比赛的数据加载失败，故返回 0 由调用方按
  「未设置」处理；但**必须留日志** —— 畸形输入是服务端格式变化的第一现场信号（旧实现静默归零，
  只能靠现场倒计时不对才发现）。
- **非零偏移额外告警一次**：本项目已知 HOJ 自建部署可能把本地时间序列化进来。带偏移时结果会
  真的换算为 UTC，日志用于暴露「这个部署的时区配置与预期不同」。
- **日期要求「年-月-日」齐全**：`2024` 这类残缺值按无法解析处理，不静默折算成 1 月 1 日 ——
  时间戳字段出现残缺值几乎必然是坏数据，返回 0 + warn 更好排障。
- **签名保持 `i64`（0 = 未设置）**：改 `Option` 会牵动 `Contest` 实体 / DTO / 前端，且
  `getContestPhase` 依赖该值；本轮只消除「静默」，把影响面控制在 adapter 层。
- **`split_timezone` 用 `get(1..)` 而非 `[1..]`**：只有日期的串传进来时 `rest` 是空串，
  直接切片会 panic（Hydro 原实现有这个未覆盖的边界）。

## 测试

`src-tauri/src/adapter/tests/time_tests.rs` 锁定：真实夹具串（`...16:00:00.000+0000`）与显式 UTC 等价、
非零偏移与半小时偏移真的换算（含 `assert_ne!` 反向锁定「旧实现会得到与 UTC 相同的值」）、
`Z`/`z` 大小写、空格分隔、非零填充、仅日期、闰日与 epoch 边界、越界月份被 clamp 不 panic、
空串/纯空白为「未设置」、畸形输入返回 0 不 panic。
