# 模块文档索引

> 本目录存放项目各个源文件的精炼文档，与 `Architecture.md` 的文件树一一对应。
> 每个 `.md` 文件描述对应源文件的功能、核心逻辑及上下文依赖关系，便于人工介入理解代码。

## 格式约定

每个模块文档包含以下小节：

```markdown
# 模块名

## 职责
一句话描述该模块/文件的职责。

## 核心类型/函数
列出关键的类型定义、函数签名及其用途。

## 直接依赖
列出该文件直接 import/use 的外部模块。

## 被依赖
列出哪些模块依赖本文件。

## 逻辑流程
简要说明关键函数的执行流程或组件的数据流。
```

## 文档维护规则

- 每次新增源文件时，必须在 `doc/modules/` 下创建对应的 `.md` 文档
- 每次修改源文件的职责、接口或依赖关系时，必须同步更新对应的 `.md`
- 目录结构与项目源文件结构保持一致
