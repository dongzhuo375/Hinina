# CI/CD 施工记录

本目录存放 CI/CD 分阶段施工（M0–M6）的过程记录与基线事实，随对应阶段施工提交入库。

- 命名约定：`m{N}-<主题>.md`（如 `m0-baseline.md`），一个阶段至少一份，多份按主题追加。
- 记录原则：只写实测结果与已落地的配置，不把计划写成现状；数字写统计口径与测量条件。
- 上游规划文档（现状评估、分阶段施工方案）为本地调研文档，位于 `doc/local/`（不入库，见 `.gitignore`）。
- 原始命令日志保存在本地 `doc/local/m0-logs/`（不入库）；入库记录只携带摘编后的数字与结论。

## 目录内容

- [m0-baseline.md](m0-baseline.md) — M0 基线冻结（2026-10-25）：工具链基线、10 条检查命令实测结果、问题分类、Ubuntu runner 准备步骤、workflow 稳定命名与 M1 阻塞性判定。
- [m1-pr-gate.md](m1-pr-gate.md) — M1 最小 PR CI（2026-10-25，PR #50）：ci.yml 结构与三项决策、行尾治理、E1 修复、首跑逐 job 结果（Ubuntu Rust 套件首跑全绿、非阻塞汇总语义实证）、合并后保护配置与验收清单。
- [m2-tests.md](m2-tests.md) — M2 关键测试补位与覆盖率基线（2026-10-25）：命令 `*_impl` 全真上下文测试、HOJ/Hydro loopback 契约测试、前端关键组合测试、V8 覆盖率基线（行 57.25% / 分支 54.48% / 语句 55.74%，只报告不卡线）。
