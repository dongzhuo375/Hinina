# Hinina 应用图标设计

> 与登录页同一套设计语言：**几何、光影、克制**（苏博内核的现代转译）。
> 目标是"精密仪器般的冷静"——选手在任务栏看到它，就像看到赛场闸机的指示灯。

## 设计概念

图标主体是 **Hinina 首字母「H」字标**，由正交矩形模块构建，三个笔画各承载一处设计语义：

| 笔画 | 形态 | 语义 |
|------|------|------|
| 左干 | 完整矩形 | 秩序与稳定，赛制的庄重感 |
| 右干 | 顶部 **45° 微妙切角**（64px 对角） | 苏博式几何切割；打破对称的呼吸感，非对称平衡 |
| 横梁 | **木色 #8C6A43**，比字干更细（72 vs 120） | 登录页输入框聚焦时"从中间向两边延展的木色线条"；也是入场闸机的横杆 |

色彩与底：

- **深色母版**：哑光炭黑底（#35383C → #2B2D30 极微弱纵向光影）+ 米白字形 #F7F6F1，顶部 1px 级边缘高光建立悬浮层级。
- **浅色变体**：米白底 #F7F6F1 + 炭黑字形 #2E3033，边缘 0.08 透明度细分界。
- 全图标**唯一强调色**是木色横梁；竹青 #5F7A6A 与朱红 #A33B2A 为状态色，不进入品牌图标。

## 视觉 Token

| 项 | 值 |
|----|----|
| 画布 | 1024×1024，字形区 512×480 居中（左右边距 288/272，上下 272/272） |
| 字干宽 | 120（母版） |
| 横梁 | 224×72，垂直居中于字形区 |
| 切角 | 右干顶部 45°，对角 64px |
| 圆角 | 母版为直角满出血；系统蒙版（macOS/Windows ≈ 22.5%）由 OS 施加，预览见 preview.html |
| 背景 / 主色 / 强调色 | #F7F6F1 / #2E3033 / #8C6A43 |

## 文件清单

| 文件 | 用途 |
|------|------|
| `icon.svg` | 深色母版（1024），主用图标 |
| `icon-light.svg` | 浅色变体，浅色任务栏 / 文档站 / 印刷 |
| `icon-mono.svg` | 单色字标（透明底，`currentColor`），系统托盘 / 菜单 / 水印 |
| `icon-small.svg` | 小尺寸优化版（16–64px），字干加粗、切角加大 |
| `icon-1024.png` … `icon-16.png` | PNG 导出（1024/512/256/128/64/32/16） |
| `preview.html` / `preview.png` | 全变体 × 全尺寸预览（含系统蒙版模拟） |

## 使用规范

- **≥ 64px**：使用 `icon.svg` 母版导出；**< 64px**：必须使用 `icon-small.svg`，小尺寸下母版切角与横梁会糊。
- 单色场景（托盘、菜单）用 `icon-mono.svg`，颜色取 #2E3033（浅底）或 #F7F6F1（深底），状态提示可用 #8C6A43。
- 图标周围保留 ≥ 字形高度 1/4 的安全区；禁止叠加文字、徽章或投影。

## 接入 Tauri

`src-tauri/icons/` 目前待填充。接入时以 `icon-1024.png` 为源执行：

```bash
npm run tauri icon path/to/icon-1024.png
```

自动生成 Windows `.ico` / macOS `.icns` / Linux 各尺寸 PNG。32px 与 16px 建议用 `icon-small.svg` 单独导出后替换，保证小尺寸清晰度。

## 禁止事项

- 禁止霓虹渐变、大圆角气泡、投影堆叠、书法/水墨元素。
- 禁止在品牌图标中使用朱红 #A33B2A（它是倒计时 < 24h 的警示色，语义冲突）。
- 禁止旋转、拉伸、改变横梁颜色或去掉切角——切角与木色横梁是图标的两个识别锚点。
